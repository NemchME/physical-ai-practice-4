# Physical AI. Практика 4: проприоцепция в визуомоторной BC-политике

Робот Franka Panda в задаче PandaPickCube (MuJoCo) учится брать куб по картинке с камеры на гриппере. В этой практике к картинке добавлена проприоцепция: 16 чисел с положениями и скоростями суставов. Изменение прошло через весь пайплайн (среда, сбор LeRobotDataset, модель, обучение, инференс). Эффект проверен контролируемым сравнением с baseline и двумя ablation-экспериментами: по модальностям и по способу обработки проприо.

Все модели обучены на одних и тех же 1000 эпизодах (100 эпох, batch 64, lr 1e-4), SR считается на 50 эпизодах с seed 999.

## Результаты

| Модель | Наблюдения | Лучший eval loss | SR (50 ep) |
|---|---|---|---|
| bc_image | изображение | 0.0340 | 36/50 (72%) |
| bc_proprio | проприоцепция | 0.0358 | 0/50 (0%) |
| bc_both_identity | изображение + проприо (напрямую) | 0.0274 | 42/50 (84%) |
| bc_both_mlp | изображение + проприо (через MLP) | 0.0256 | 47/50 (94%) |

Главный вывод: проприоцепция подняла SR с 72% до 94% при тех же данных, и провалов при переносе куба стало почти в 5 раз меньше. Сама по себе она задачу не решает (без камеры модель не знает, где куб), а работает только в паре с картинкой. Отдельный MLP для проприо даёт ещё +10 п.п. к прямой конкатенации.

Вместо 10 000 эпизодов использовано 1000, а обучение шло в несколько заходов из-за лимитов бесплатного Google Colab, подробности в `reports/colab_limits.md`.

## Структура

- `code` - файлы проекта с моими изменениями
- `reports` - отчёты по урокам: baseline, среда, датасет, обучение, rollout, ablation и итоги, лимиты Colab
- `screenshots` - скриншоты тестов, обучения, TensorBoard, инференса и окон Colab
